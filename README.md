# منصة امتحانات التحول الرقمي

## Digital Transformation Exam Platform

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-blue)](https://alexandriadeveloper.github.io/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

### وصف المشروع (Project Description)

منصة امتحانات التحول الرقمي هي موقع ويب تفاعلي مصمم لتقييم وتطوير مهارات المستخدمين في مجالات التحول الرقمي المختلفة. يوفر الموقع مجموعة متنوعة من الامتحانات التفاعلية تغطي مواضيع مثل تقنية المعلومات، أنظمة التشغيل، وتطبيقات Microsoft المختلفة.

This is an interactive web platform designed to assess and develop users' skills in various digital transformation fields. The site offers a variety of interactive quizzes covering topics such as information technology, operating systems, and various Microsoft applications.

### الميزات الرئيسية (Key Features)

- **امتحانات تفاعلية**: مجموعة شاملة من الامتحانات مع أسئلة متعددة الخيارات وشرح مفصل للإجابات.
- **توقيت الامتحانات**: نظام توقيت مدمج لإضافة الضغط الزمني وتحسين التركيز.
- **ترتيب عشوائي**: خيار ترتيب الأسئلة عشوائياً أو بالترتيب الطبيعي.
- **تصميم متجاوب**: متوافق مع جميع الأجهزة والشاشات.
- **واجهة باللغة العربية**: دعم كامل للغة العربية مع اتجاه RTL.

- **Interactive Quizzes**: Comprehensive set of quizzes with multiple-choice questions and detailed answer explanations.
- **Timed Exams**: Built-in timer system to add time pressure and improve focus.
- **Random Ordering**: Option to randomize question order or keep natural sequence.
- **Responsive Design**: Compatible with all devices and screen sizes.
- **Arabic Interface**: Full Arabic language support with RTL direction.

### فئات الامتحانات (Exam Categories)

1. **IT & Operating System** - اختبار مهاراتك في تقنية المعلومات وأنظمة التشغيل.
2. **Word** - امتحانات تغطي مفاهيم Microsoft Word الأساسية.
3. **PowerPoint** - اختبار استخدام Microsoft PowerPoint للعروض التقديمية.
4. **Excel** - تقييم مهارات استخدام Microsoft Excel للجداول والتحليل.
5. **Access** - امتحانات حول Microsoft Access لقواعد البيانات.
6. **Mobile Application** - تطبيقات محمولة من Microsoft.
7. **Web Search** - أدوات البحث على الويب.

- **HTML5**: هيكل الموقع الأساسي.
- **CSS3**: التصميم والتنسيق مع Tailwind CSS.
- **JavaScript**: التفاعل والوظائف الديناميكية.
- **Tailwind CSS**: إطار عمل CSS للتصميم السريع والمتجاوب.
- **Google Fonts**: خطوط Cairo للنصوص العربية.

- **CSS3**: Styling and layout with Tailwind CSS.

### التثبيت والإعداد (Installation & Setup)

1. **استنساخ المستودع**:
   ```bash
   git clone https://github.com/AlexandriaDeveloper/AlexandriaDeveloper.github.io.git
   cd AlexandriaDeveloper.github.io
   ```

2. **فتح الموقع محلياً**:
   - افتح ملف `index.html` في متصفح الويب الخاص بك.
   - أو استخدم خادم محلي بسيط:
     ```bash
     python -m http.server 8000
     ```
     ثم انتقل إلى `http://localhost:8000`.

3. **نشر على GitHub Pages**:
   - الموقع منشور تلقائياً على GitHub Pages.
   - يمكن الوصول إليه عبر: https://alexandriadeveloper.github.io/
